# Prisma: actualizaciones

Archivos del programa Prisma para portatil (Windows). Prisma se actualiza solo desde aqui.

- Instalar por primera vez: descarga `Prisma-portatil.zip` de la [release "portatil"](../../releases/tag/portatil), extrae todo y abre `INSTALAR.cmd`.
- El programa no trae claves ni configuracion: eso se entrega aparte y en privado.
- Cada version va firmada (Ed25519). Prisma no instala nada que no lleve esa firma y cuyo SHA-256 no coincida.
